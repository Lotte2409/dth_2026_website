# Open Source

## Disadvantages of Open Source 
Open Source does not only have advantages but comes with a few disadvantages as well which users of Open Source should be aware of, or if you want to use Open Source. 

### Main Disadvantages 
One of the main disadvantages is linked to one of the advantages, which is transparency. Everybody who has some knowledge of coding can edit the source code in Open Source, which can lead to security issues, as some might not have good intentions with editing the source code. This can include things like identity theft or harmful transactions. [Open-Source Software –Benefits and Drawbacks](https://ijarsct.co.in/Paper11689.pdf)

Another issue is that Open Source, is not always user friendly, so if somebody does not have technical knowledge, it might be hard to navigate around. In addition due to it having so many collaborators it is harder to find support when running into issues. You most likely have to figure out these issues yourself or turn to the internet for help. 

### Is it really a disadvantage of Open Source?
One thing which is not necessarily an Open Source issue but needs to be kept in mind is that Open Source might not be compatible with your Operating System due to regulations of the Closed Source software provider.
