# Open Source

## Advantages of Open Source 

***A short introduction to open Source*** 
Open Source: Open Source is very transparent. People can see code changes, and many people, up to thousands, work on it together. This strengthens collaboration and innovation. Meaning that it is a key concept for technology currently and in the future. One of the most well-known Open-Source software is *[Linux](https://github.com/torvalds/linux)* which can be accessed through the github.

### Linux 
Linux is one of the best Open-Source software providing an alternative for Closed Source software such as *Windows*. It provides users with an alternative, in which they can modify the source-code and is most Open Source operating systems are free to use. In addition Open Source like Linux are providing an option to avoid vendor lock-in, giving users more freedom of choice when it comes to their software providers. 

## Top three advantages 
### Open Source has many advantages; this section of the page is going to focus on three of them 

- Open Source, generally speaking, is more cost-efficient as it is free to use. This means that it is more accessible for the general public and smaller companies who might not have the budget for it otherwise. 
- Another huge advantage of Open Source is that it is collaborative work, meaning that Open Source has a community behind it. When an error is detected, there are people working on a bug fix quickly and thus Open Source has a great chance of working more smoothly.  
- As mentioned earlier, transparency is one of the most defining factors of Open Source, which is a vital advantages. Every person who knows a bit a about how Open Source can see exactly how it works. You can easily review the code and adapt to your needs, as you have access to the data.
